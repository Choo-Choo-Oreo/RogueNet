# Mine: design brief

A working mine. Structure and order: straight, consistent corridors that
connect one place to the next, and rooms that are mazes with a function.

- **Corridors: orderly and consistent.** Second loosest. A mine shaft is a
  built thing, so corridors run straight, turn at right angles, and look the
  same from one end of the dive to the other. Timber frames the doorways and
  props up long tunnels.
- **Rooms: functional mazes.** Second tightest rooms. The maze comes from what
  the room is for, not from decoration: cart tracks down the middle, ore
  galleries branching off, supports and stacks in the way.
- **Minecarts.** Typically a track runs down the middle of a room or corridor.
  The plank "tracks" in the existing rooms are placeholders for a rail floor.
- **Doorways: 1 wide.**
