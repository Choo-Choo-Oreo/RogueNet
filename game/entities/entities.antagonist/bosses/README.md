# Bosses

A creature JSON in this folder is a boss. There is no `boss` field: the folder decides, so
moving a file here or out of here changes its role. Bosses walk through minions and minions
step out of their way. A boss is picked for a boss room through the room's
`favored_antagonist`. The format, ids and the full list are in
[`../README.md`](../README.md). Today: `minotaur`.
