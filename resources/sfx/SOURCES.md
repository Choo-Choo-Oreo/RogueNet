# Where the sounds came from

Every sound under `resources/sfx/combat/`, `effects/` and `ambiance/` was cut from a Pixabay
recording on 2026-09-25 (Pixabay Content License: free in games, no credit needed). Claude
picked, cut, layered and levelled them without listening, so every one is waiting on someone's
ears. Each is as loud as the placeholder it replaced, so the balance the code was set for holds.
The number is the end of the `pixabay.com/sound-effects/` page address.

Still synthesised placeholders (no good match found yet): `combat/attacks/taunt.wav`,
`combat/hurt/drone.wav`, `effects/lava/step_1-3.wav`. The music and `ui/` have their own notes.
